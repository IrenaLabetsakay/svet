# Feature: Страница с графиками

## Описание

Новая страница `/stats` — статистика и аналитика компании в виде интерактивных графиков.

## Маршрут

`/stats` → `app/stats/page.tsx`

## Библиотека

**Recharts** — React-first, хорошо интегрируется с Next.js, поддерживает SSR.

```bash
npm install recharts
```

## Графики

### 1. Линейный график — Количество проектов по месяцам

- Тип: `LineChart`
- Данные: помесячная динамика выполненных проектов за год
- Ось X: месяцы (Янв–Дек)
- Ось Y: количество проектов

### 2. Столбчатый график — Выручка по кварталам

- Тип: `BarChart`
- Данные: выручка по кварталам за 2 года (2024 и 2025)
- Ось X: кварталы (Q1–Q4)
- Ось Y: сумма в тысячах рублей
- Цвета: amber (2024), slate (2025)

## Компоненты

- `app/stats/page.tsx` — серверный компонент, metadata
- `components/stats/ChartsSection.tsx` — клиентский компонент с графиками (`"use client"`)

## Стиль

- Фон: `slate-900` (как остальные страницы)
- Акцент: `amber-400`
- Заголовок страницы + описание над графиками
- Адаптивная сетка: 1 колонка на мобильных, 2 на desktop (lg:grid-cols-2)

## Тестовые данные

Встроены прямо в компонент `ChartsSection.tsx` — реальный бэкенд не требуется на этапе разработки.
